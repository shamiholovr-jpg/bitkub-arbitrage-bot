# Трекер отношений

Мобильное приложение (Expo / React Native + TypeScript) для трекинга динамики отношений: фиксация конфликтных
событий по категориям, статистика и графики за период, плюс AI-советник на базе Claude API, опирающийся на
популярные модели психологии отношений.

## Возможности

- **Быстрое логирование** — на дашборде одним тапом отмечается недопонимание/спор/конфликт/большая ссора (плюс
  свои категории), с указанием даты, интенсивности (1–5), краткой причины и заметки.
- **История** — лента всех записей с фильтром по категории и удалением.
- **Статистика/динамика** — «индекс напряжения» (0–100, эвристика на основе тяжести категории × интенсивность,
  усреднённая по окну), тренд-линия за 7/30/90 дней, круговая диаграмма по категориям, недельная разбивка по
  категориям за последние 8 недель.
- **AI-советник** — на вкладке «Советник» приложение собирает статистику и последние записи, отправляет их в
  Claude API вместе с вопросом пользователя и получает персонализированные, но безопасные рекомендации (без
  диагнозов; при признаках небезопасных отношений — направление к специалисту). Там же — библиотека коротких
  карточек по проверенным моделям: четыре всадника Готтмана, стили привязанности, ненасильственное общение,
  стили поведения в конфликте (Томас–Килманн), языки любви, попытки примирения.
- **Настройки** — свой API-ключ Anthropic (хранится только на устройстве, в защищённом хранилище — Keychain/
  Keystore через `expo-secure-store`), управление категориями (скрыть дефолтные, добавить свои), экспорт/импорт
  данных в JSON, полная очистка данных.

## Архитектура и хранение данных

Это MVP без бэкенда: все данные (записи, кастомные категории, история чата с советником) хранятся локально на
устройстве через `@react-native-async-storage/async-storage`. API-ключ Claude — отдельно, через
`expo-secure-store`. Ничего не отправляется на сервер приложения (его просто нет) — единственный внешний вызов
это прямой запрос с устройства к `api.anthropic.com`, когда пользователь открывает вкладку «Советник» и просит
совет.

```
relationship-tracker/
  App.tsx                    — навигация (bottom tabs + модалка AddEntry)
  src/
    types.ts                 — Category, Entry, AdvisorMessage
    constants/
      categories.ts          — категории по умолчанию (severity 1..4)
      psychology.ts          — статичная библиотека психологических концепций
    storage/
      storage.ts             — AsyncStorage: записи, категории, история советника, экспорт/импорт
      secureStorage.ts        — SecureStore: API-ключ Claude
    utils/
      date.ts, stats.ts, id.ts — даты, агрегация статистики/индекс напряжения, id
    context/EntriesContext.tsx — React Context с CRUD для записей/категорий
    services/claudeApi.ts     — прямой вызов Anthropic Messages API
    components/               — CategoryBadge, CategoryPicker, EntryCard, StatCard
    screens/                  — Dashboard, AddEntry, History, Stats, Advisor, Settings
```

## Индекс напряжения (friction score)

Простая прозрачная эвристика, не клиническая шкала: для каждого дня в окне суммируется
`severity(категории) × (интенсивность / 5)`, делится на число дней окна и масштабируется в 0–100
(100 ≈ ежедневная «большая ссора» максимальной интенсивности). График использует скользящее среднее за 7 дней,
чтобы не скакать от одной записи. Реализация — `src/utils/stats.ts`.

## Запуск

```bash
cd relationship-tracker
npm install
npm run start      # Expo Dev Tools — далее выбрать iOS/Android/Web
npm run android     # или сразу под конкретную платформу
npm run ios
```

Для AI-советника получите API-ключ на console.anthropic.com и вставьте его на вкладке «Настройки» — без него
работают трекинг и статистика, вкладка «Психология» доступна всегда.

## Известные ограничения MVP

- Данные не синхронизируются между устройствами (нужен бэкенд, сознательно не делали для MVP — см. историю
  разработки/трекер задач).
- API-ключ Claude вводится и хранится на самом устройстве пользователя (BYO key): без бэкенда нет способа
  спрятать ключ от конечного пользователя, только от третьих лиц — это стандартный компромисс для клиентских
  MVP-приложений с прямым вызовом LLM API.
- Пикер даты для бэкфила записей — упрощённый (ГГГГ-ММ-ДД текстом), без нативного календаря.
- Проверено сборкой (`expo export`) и `tsc --noEmit`; полный прогон на реальном iOS/Android-устройстве в этой
  сессии не выполнялся (нет симулятора в окружении).
